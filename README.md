# VinCv — проверка автомобиля по VIN (сайт vincv.ru + боты MAX и Telegram)

Проверка автомобиля по VIN, госномеру или ссылке на объявление на данных API
[avtovincod.ru](https://avtovincod.ru). Реализует этапы 1–2 спецификации MVP (рабочее название проекта — «Штурман Авто»):
лендинг с бесплатной экспресс-проверкой, Telegram-бот, каскад запросов к провайдеру по тарифам,
RedactionLayer, кэш по VIN, PDF-отчёт и биллинг (разовые отчёты и пакеты).

## Быстрый старт (без токена, на офлайн-образцах)

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
uvicorn shturman.api.app:get_app --factory --reload   # http://localhost:8000
pytest
```

`PROVIDER_MODE=mock` (по умолчанию) отдаёт без сети настоящие ответы avtovincod.ru на тестовые
значения (`shturman/provider/samples/`). Пример полного отчёта — `/example`, PDF — `python scripts/preview_report.py`.

## Подключение avtovincod.ru

1. Зарегистрироваться в личном кабинете avtovincod.ru и получить токен.
2. В `.env`: `PROVIDER_MODE=live`, `AVC_TOKEN=...`.
3. Обновить образцы ответов (бесплатно, тестовые значения работают даже при нулевом балансе):
   ```bash
   python scripts/dump_test_responses.py
   ```
   Ответы лягут в `tests/fixtures/live/`; при изменении схемы скопируйте их в `shturman/provider/samples/`
   и поправьте анализаторы в `shturman/rules.py`.

Тестовые значения провайдера: VIN `X7TEST00000000001`, госномер `Т000ТТ00`, кузов `TEST-0000001`,
СТС `0000000000`. По ним любой метод отвечает образцом с `"testMode": true` и `billing.charged = 0`.

## Тарифы и каскад

| Тариф | Методы avtovincod.ru |
|---|---|
| Экспресс (0 ₽, лимит в сутки) | `decode`, `pledge`, `taxi`, `elpts`, `accidents` (+ `gos2vin` для госномера) |
| Базовый | + `score`, `brief`, `probeg`, `price`, `fines`* |
| Досье | + `vin`, `osago-history`, `offers`, `plate-history`, `pros-cons`, `nomerogram`, `recalls`, `customs`*, `lizing`*, `lawsuits`*, `sharing`* |
| Досье+ | + `accidents-rt` (асинхронный, с опросом `task`), `service`* |

\* гейты — дорогие методы только по условию: штрафы — если `/brief` вернул СТС; таможня — VIN не
отечественной сборки (не X/Z); лизинг — владелец-юрлицо или авто моложе 7 лет; суды — есть залог
или ограничения; каршеринг — моложе 6 лет; сервисная история — моложе 10 лет.
Набор методов меняется в `shturman/cascade.py`, цены — в `.env`.

При повышении тарифа уже полученные разделы не запрашиваются повторно; ответы кэшируются
по VIN с TTL по типу источника (`shturman/provider/methods.py`). Ошибки провайдера
(`NOT_ALLOWED`, сеть и т. п.) не роняют отчёт — раздел помечается «нет данных».
Расходы по блоку `billing` пишутся в таблицу `provider_log`.

## Личный кабинет и каталог специалистов

- **Вход через Яндекс ID** (`/auth/yandex`): приложение на oauth.yandex.ru, Redirect URI
  `https://vincv.ru/auth/yandex/callback`, доступы «почта» и «логин, имя»; ключи — `YANDEX_CLIENT_ID/SECRET`.
- **Вход по почте и паролю** (`/register`, `/login`): пароли хранятся как хеш scrypt, подтверждение адреса
  и сброс пароля — по ссылке из письма (нужен SMTP, `SMTP_*` в `.env`; без него ссылки пишутся в лог).
  Не больше 10 попыток входа/регистрации за 15 минут с одного IP.
- **Привязка мессенджера** к кабинету (кнопка «Привязать MAX» → подтверждение в боте): проверки, пакеты,
  оплаты и анкета из бота переносятся в кабинет, аккаунты объединяются. Из кабинета, созданного через бота,
  можно добавить вход по почте.
- **Вход через бота**, без паролей и почты: `/login` → «Войти через MAX/Telegram» → подтверждение в боте →
  страница сама пускает в кабинет (`shturman/auth.py`). Из бота — команда `/cabinet` (одноразовая ссылка, 10 минут).
- **Кабинет** `/cabinet`: баланс, история проверок с отчётами (HTML и PDF), покупка отчётов и пакетов через
  Robokassa, «Досье» из пакета. Проверки с сайта под входом сохраняются в кабинет.
- **Хранение отчётов**: в базе лежат данные проверки (~3–15 КБ), PDF собирается при открытии — 10 000 полных
  отчётов занимают меньше 0,5 ГБ. Раз в сутки `shturman/maintenance.py` удаляет истёкший кэш провайдера и
  анонимные экспресс-проверки с сайта старше `ANON_CHECKS_RETENTION_DAYS` (30 дней).
- **Каталог специалистов** `/pros`: анкеты подборщиков, выездной диагностики и перекупов с фильтром по городу
  и поиском (`shturman/pros.py`); виды: автоподбор, выездная диагностика, продажа авто, аварийное вскрытие авто. Анкета → модерация в панели администратора → публикация.
  Контакты открываются по кнопке и считаются вместе с просмотрами — статистика видна владельцу анкеты.
- **Задел под монетизацию**: у анкеты есть `plan` (free/pro) и `featured_until` — такие анкеты уже поднимаются
  выше в выдаче и помечаются «Рекомендуем»; статистика просмотров и контактов по дням (`pro_stats`).
  Чтобы начать продавать размещение, достаточно добавить продукт в `billing.py` и выставлять эти поля при оплате.

## Панель администратора

Живёт на секретном адресе `ADMIN_PATH` (например `/ops-k7f2x9q4m1abcd23`); на `/admin` и любом другом адресе —
обычная 404. Пустой `ADMIN_PATH` — панели нет вовсе. Секретный адрес защищает от сканеров, а не от
целенаправленной атаки: настоящая защита — пароль + 2FA + белый список IP.

- **Сотрудники — только из `.env`** (`ADMIN_USERS`); аккаунты сайта, Яндекс ID и мессенджеров к панели доступа
  не имеют, из браузера сотрудника не добавить. Управление — из терминала сервера:
  `./deploy/admin.sh init` (сгенерировать адрес), `add <логин> --role admin|support` (спрашивает пароль,
  показывает QR-код для приложения 2FA прямо в терминале и проверяет первый код), `passwd`, `reset-2fa`,
  `role`, `remove`, `list`. В `.env` хранится только scrypt-хеш пароля; файл — `chmod 600`.
  После изменений: `docker compose up -d api`. Убранный из `.env` сотрудник теряет и открытые сессии.
- **Вход:** одна форма — логин, пароль и код из приложения (Яндекс Ключ, Google Authenticator, Aegis).
  Ошибка всегда одинаковая («неверный логин, пароль или код»), время ответа для несуществующего логина
  то же. Код принимается один раз. 5 неудач с IP за 15 минут или 10 на логин за час — пауза.
  Сессия — отдельная cookie `vadm` (HttpOnly, Secure, SameSite=Strict, только на пути панели), `STAFF_MFA_HOURS` ч.
- **Белый список IP** `ADMIN_ALLOWED_IPS` (адреса и подсети): с остальных панель отвечает 404 даже на секретном адресе.
- **Роли:** *поддержка* — сводка, клиенты (поиск по почте, номеру, ID в мессенджере, VIN, госномеру),
  начисление/списание отчётов с причиной, блокировка клиентов, заказы и проверка оплат в Robokassa,
  модерация и продвижение анкет, создание бэкапа; *администратор* — всё то же + скачивание, восстановление
  и удаление бэкапов.
- **Бэкапы:** создание одной кнопкой (или `n b`), список, скачивание, восстановление. Восстановление — только
  администратору, со свежим кодом 2FA и словом ВОССТАНОВИТЬ; перед ним автоматически сохраняется копия
  текущей базы, восстановление идёт одной транзакцией (при ошибке база не меняется). В панели видны и ночные
  копии из `deploy/backup.sh`. Проверено на PostgreSQL 16 с утилитами версии 17.
- **Финансы** (только администратор, `g f`): отчёт о прибылях и убытках за месяц или любой период — выручка
  по продуктам, эквайринг (% из настроек), себестоимость (фактические списания avtovincod.ru: платные отчёты
  отдельно, бесплатные проверки — как расход на привлечение), операционные расходы по категориям, налог
  (УСН 6 %, УСН 15 % с минимальным 1 %, НПД, без налога), валовая/операционная/чистая прибыль и маржа,
  сравнение с прошлым периодом. Юнит-экономика: средний чек, ARPPU, себестоимость отчёта, конверсия новых
  пользователей в оплату, точка безубыточности, неизрасходованные отчёты в пакетах. График и таблица за
  12 месяцев, выгрузка CSV за 24 месяца. Расходы и прочие доходы вносятся вручную, в том числе ежемесячные
  (сервер, домен, подписки). Метод кассовый, месяцы — по Москве (`shturman/admin/finance.py`).
- **Журнал:** каждое действие сотрудника по логину (входы и неудачные попытки, начисления, блокировки, бэкапы) с IP.
- **Тревоги** (расход у провайдера сверх наших запросов, низкий баланс, ошибки) — в панели и личными
  сообщениями на `ALERT_MAX_USER_IDS` (ID в MAX — команда `/id` в боте) и `ALERT_TG_CHAT_IDS`.
- **Горячие клавиши:** `g d` сводка, `g c` клиенты, `g o` заказы, `g m` анкеты, `g b` бэкапы,
  `g s` сотрудники, `/` поиск клиента, `n b` создать бэкап, `?` подсказка.

## Безопасность

**Оплата.** Сумма и получатель заказа берутся только из базы: в Robokassa уходит номер заказа (InvId),
а кому начислить и сколько — решает сервер. Уведомление об оплате (ResultURL) принимается только с подписью
паролем №2, которого нет в ссылке на оплату; сумма сверяется с ценой заказа; тестовые платежи отвергаются,
если `ROBOKASSA_TEST=false`. Повторные и одновременные уведомления не начисляют дважды (блокировка строки
заказа + уникальный номер платежа). Страница успешной оплаты сама ничего не начисляет — только спрашивает
статус у Robokassa. Отчёты из пакета списываются атомарно (`UPDATE … WHERE credits > 0`).
При `ROBOKASSA_TEST=true` или `DEV_FAKE_PAYMENTS=true` на сайте с HTTPS — предупреждение в логе и в панели.

**Доступ к данным.** Проверку можно купить, дособрать из пакета или открыть в боте только её владельцу.
Ссылка на отчёт `/r/<id>` — случайный ключ (122 бита), отчёты закрыты от поисковиков; ПДн третьих лиц в них нет.

**Вход.** Пароли — scrypt; не больше 10 попыток входа/регистрации за 15 минут с IP; смена пароля закрывает
остальные сессии; cookie сессии HttpOnly, Secure, SameSite=Lax; POST-формы проверяют Origin. Вход и привязка
через бота подтверждаются в боте. Яндекс ID: `state` против подмены входа; к аккаунту с той же почтой
привязываемся, только если почта в нём подтверждена.

**Бюджет.** Бесплатные проверки ограничены на аккаунт, на IP (сколько бы аккаунтов с него ни было) и общим
дневным лимитом (`FREE_CHECKS_PER_IP_PER_DAY`, `FREE_CHECKS_GLOBAL_PER_DAY`); выдача PDF — не чаще 30 раз
за 10 минут с IP. Caddy запрещает встраивание сайта во фреймы и отдаёт HSTS.

**Тревоги.** Раз в 5 минут (`shturman/alerts.py`, только при `PROVIDER_MODE=live`): «чужой расход» —
баланс у avtovincod.ru уменьшился больше, чем списали наши запросы (признак утечки токена; баланс узнаётся
и без трафика — бесплатным запросом по тестовому VIN раз в 30 минут); расход за час и за сутки; остаток на
балансе; всплеск ошибок источников. Тревога — в сводке панели и личным сообщением сотрудникам в MAX
(и Telegram), не чаще раза в 3 часа на одну и ту же. Пороги — `ALERT_*` в `.env`.

**Контейнеры.** Сайт и боты работают от пользователя `app` (uid 1000), без capabilities ядра и с
`no-new-privileges`; код приложения в контейнере изменить нельзя. `.dockerignore` не пускает в образ `.env`,
базы, бэкапы и тесты. Файлы бэкапов — с правами 640.

**Сервер (сделать вручную).** Вход по SSH-ключу и запрет входа по паролю, `fail2ban`; `.env` с правами 600
(делает `setup.sh`); регулярно скачивать копию базы к себе.

## Документы для модерации Robokassa

Страницы `/offer` (публичная оферта), `/privacy` (политика обработки ПДн по 152-ФЗ) и `/contacts`
собираются из реквизитов в `.env`: `LEGAL_NAME`, `LEGAL_STATUS`, `LEGAL_INN`, `LEGAL_OGRN`, `LEGAL_ADDRESS`,
`CONTACT_EMAIL`, `CONTACT_PHONE`. Незаполненные реквизиты подсвечиваются красным. Цены в оферте берутся из
тарифов. Тексты — шаблон: перед запуском покажите их юристу. Также есть `robots.txt` и `sitemap.xml`.

## Обновление базы

Новые колонки в существующих таблицах создаются автоматически при запуске (`db._add_missing_columns`):
данные не трогаются. Удаление и переименование колонок так не делаются — для этого понадобится Alembic.

## Светофор

`shturman/rules.py`: каждый метод разбирается в раздел со статусом, из статусов складывается светофор.

- 🔴 **Критично** — активный залог, розыск, ограничения ГИБДД, действующий лизинг, уменьшение пробега
  по техосмотрам/сервису, ограничения в ЭПТС, прекращённая регистрация, 2+ ДТП.
- 🟡 **Внимание** — такси (разрешение или ОСАГО «такси»), ДТП, неоплаченные штрафы, каршеринг, суды,
  завершённый лизинг, отзывные кампании, пробег в объявлении меньше ранее зафиксированного, 4+ владельцев.
- 🟢 **В порядке** — остальное, но только если хоть один реестр подтвердил, что автомобиль существует
  (регистрация, ПТС, техосмотры, полисы, залоги и т. п.).
- ⚪ **Нет данных** — записей об автомобиле в реестрах нет (расшифровка VIN, цена и отзывы о модели не в счёт)
  или источники не ответили. Если не ответил реестр залогов или проверка ограничений, сигнал не выше жёлтого.

Балл 0–100: из 100 вычитается вес каждого риска (по умолчанию 30 за красный, 10 за жёлтый, у отдельных
правил свой вес). Светофор показывается в PDF, на лендинге и в сообщениях бота.

## Персональные данные

`shturman/redaction.py` удаляет поля с ПДн (ФИО, дата рождения, паспорт, телефоны, e-mail,
залогодатель, должник…) и маскирует ФИО/телефоны/e-mail в тексте **до** записи в кэш и БД.
Хостинг — VPS в РФ (152-ФЗ).

## MAX-бот и оплата через Robokassa

```bash
python -m shturman.bot.max
```

Сценарий тот же, что в Telegram: `/start` → роль → VIN/госномер/ссылка → экспресс-результат со светофором →
кнопка тарифа → ссылка на оплату Robokassa (карта, СБП) → отчёт PDF приходит в чат
(на Windows без GTK — HTML). Подборщики могут прислать список VIN, команды `/balance`, `/history`,
`/tariffs`, `/help`. Клиент MAX Bot API — `shturman/bot/max_api.py` (сверен с SDK maxapi 1.2.4).

Оплата подтверждается двумя путями (`shturman/orders.py`):
1. **Уведомление Robokassa** на `https://<ваш-домен>/pay/robokassa/result` (Result URL в ЛК, метод POST) —
   нужен публичный сервер. Success URL — `/pay/robokassa/success`, Fail URL — `/pay/robokassa/fail`.
2. **Опрос статуса счёта** (OpStateExt) каждые 15 с, а также по кнопке «Я оплатил — проверить» —
   работает и на домашнем компьютере, без публичного адреса (`ROBOKASSA_POLL_STATUS=true`).

Чек по 54-ФЗ передаётся в параметре `Receipt` (`ROBOKASSA_RECEIPT=true`), для самозанятых —
подключите «Робочеки» в ЛК. Для разработки без платёжки: `DEV_FAKE_PAYMENTS=true`.

## Telegram-бот

```bash
TELEGRAM_BOT_TOKEN=... TELEGRAM_BOT_USERNAME=... python -m shturman.bot
```

`/start` → выбор роли (разово / подборщик + статус физлицо/ИП/самозанятый/ООО) → VIN/госномер/ссылка
→ экспресс-результат с кнопками тарифов → оплата Telegram Payments (ЮКасса/СБП,
`TELEGRAM_PAYMENT_TOKEN`) → PDF. Подборщик может прислать список VIN (по строке на каждый):
при наличии пакета сразу приходят PDF «Досье». Команды: `/balance`, `/history`, `/tariffs`, `/help`.
Кнопка «Полный отчёт» на лендинге ведёт в бот по deep-link `?start=chk_<id>`.
Для разработки без платёжки: `DEV_FAKE_PAYMENTS=true`.
